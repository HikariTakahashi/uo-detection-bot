# Pi導入・動作確認

2026-11-14 JST。Raspberry Pi 5、8GB RAM、Debian 13 ARM64、Python 3.13.5。
実際の導入先: `/home/user/laya-sandbox`。

## 検証結果

- 専用venvへのLaya 0.4.31 / PyTorch 2.9.1+cpu導入成功。`pip check` 成功。
- 固定したMultilingualモデルを取得し、オフライン設定下で読み込み・推論成功。
- `python3 -m unittest discover -s experiments/laya -p 'test_*.py' -v`: ローカル5件成功。
  同じ5件はPiでも成功。URL除外、入力制限、切り捨て時の保留を確認。
- 実際のSSH対話端末で日本語を入力し、結果表示と `/quit` による終了を確認。
- 対話モード実行中の2個目の起動は終了コード1で拒否。
- CPU制限はcgroupの `cpu.max = 100000 100000` で確認。
- このPiはmemory cgroupが無効。実効性を確認したうえで、
  メモリ制限を `RLIMIT_AS = 4294967296`（仮想アドレス空間4GiB）へ変更。
  カーネル設定変更・再起動は実施していない。
